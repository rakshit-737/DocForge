## Design Specificity Verdict

**Authored-for-this-product.** No unrelated product ships this chrome unchanged without reading as a print shop.

**LLM assessment:** one metal (brass) used exactly twice; felt proof-table with lamp vignette instead of the category-standard gray canvas; status language native to the room (composing ticker, type-sort busy indicator, ink-stamp autosave); Garamond masthead/modals/empty state; even the light theme is authored ("daylit workshop," not an inversion). Interchangeable parts exist (feather-style icons, standard modal skeletons, generic toast pill) but the composition is unmistakably this product's.

**Deterministic scan:** static — 1 advisory on src/index.html (51 em-dashes, product voice), 4 warnings on src/app.css (2× `margin-left` transition on the settings drawer, 2× side-tab on the toolbar colour glyphs). ## Overall Impression

A design language carried to the bone: the metaphor governs behavior (waiting = typesetting, autosave = ink stamp), not just paint, which is why real density reads calm. The gap is reach, not concept — the most-polished chrome in the room is partly invisible to keyboards, screen readers, and 1366px laptops, and the journey's emotional finale is outsourced to Chrome's print dialog. Single biggest opportunity: make the crafted experience reach everyone who can already see it.

## What's Working

1. **The world governs behavior, not just paint.** Busy state is typesetting; progress is a folio being composed; toasts are proof slips; the PDF editor is "a proofing bench in the same room." This coherence is why 32 toolbar controls still read as calm.
2. **Status honesty at every timescale.** Keystroke → "…" → "Autosaved" stamp; render → "p. 4…" → page count; export → in-button spinner → outcome toast. The user always knows whether work is safe and whether the machine is running.
3. **UX copy that respects the reader.** Confirms state exactly what survives; lint explains consequences, not rules; template entries give a reason to choose each.

## Priority Issues

**[P1] Layout toggles and colour swatches don't exist for keyboard or assistive tech.**
- **Why it matters:** `.toggle input { display:none }` removes all 7 Layout checkboxes from tab order and the accessibility tree; the 8 accent swatches and colour-menu grid cells are unfocusable divs. A keyboard or screen-reader user cannot enable a cover page or page numbers — core outcomes.
- **Fix:** visually-hidden checkbox pattern (`position:absolute; opacity:0`) so `:focus-visible` rings the `.tg`; swatches become `<button aria-label aria-pressed>`.
- **Suggested command:** /impeccable harden

**[P1] Toolbar tools silently disappear at common laptop widths.**
- **Why it matters:** `.tbrow` clips with hidden scrollbars; with the drawer open at 1180–1500px, alignment/TOC/page-break tools vanish with zero affordance (measured scrollWidth 552/586 vs clientWidth 468). Students on 1366×768 conclude the tool doesn't exist.
- **Fix:** end-of-row fade + chevron affordance, or an overflow "⋯" popover.
- **Suggested command:** /impeccable adapt

**[P1] Modals have no dialog semantics and no focus containment.**
- **Why it matters:** overlays are plain divs — no `role="dialog"`, no `aria-modal`, focus never moves in, Tab walks the background (verified: Help open, Tab lands on #btnDark behind the scrim). The confirm dialog guards destructive actions.
- **Fix:** `role="dialog" aria-modal aria-labelledby`, move focus in, trap Tab, restore on close.
- **Suggested command:** /impeccable harden

**[P2] Replace All destroys undo.**
- **Why it matters:** `replaceAll()` assigns `editor.value` wholesale, wiping the textarea's native undo stack — the bulk operation most likely to go wrong is the one that can't be taken back, in an app that trained users Ctrl+Z works.
- **Fix:** `setRangeText(next, 0, editor.value.length)`; toast "Replaced 14 — Ctrl+Z undoes."
- **Suggested command:** /impeccable harden

**[P2] The studio masthead stays armed inside the PDF bench.**
- **Why it matters:** in pdf-mode, Templates/New/Open/Save/Settings remain live over the bench; a template loaded there silently replaces the hidden studio document; Settings clicks do nothing.
- **Fix:** hide/disable studio-only masthead controls under `body.pdf-mode` (CSS hook exists — `.doc-id` already does this).
- **Suggested command:** /impeccable harden

## Persona Red Flags

**Alex (power user):** no Ctrl+1/2/3 headings, no Ctrl+K link — the four most frequent structural acts need the mouse. Replace All kills Ctrl+Z. Tab indents, Shift+Tab doesn't outdent. Ctrl+S downloads a fresh file every save — a save-habituated Alex fills Downloads by lunch. Find says "2 found," never "2 of 14"; no case/regex toggles; matches not highlighted.

**Sam (accessibility):** the P1 trio above. 42 tab stops from page top to the textarea (no roving tabindex on `role="toolbar"`). No `aria-live` on #pgInfo/#findCount; #busy is aria-hidden with no textual equivalent — rendering is silent to a screen reader. Positives verified: brass focus ring visible both themes, #saveState has role="status", tooltips copied to aria-labels at boot, statusbar contrast honest (the kbd hint at 4.3:1 is the exception).

**Jordan (first-timer):** the export cliff — PDF requires knowing "Save as PDF" + untick headers/footers; the one toast explaining it dies under the dialog. "#lintBadge: 2 checks" is ambiguous ("2 warnings" tells the truth). Colour menus emit `[text]{color=#c00000}` — code Jordan didn't write and can't name. Font optgroup label "Word fonts — this device, named in the .docx" compresses a contract into jargon.

## Questions to Consider

1. **Why does the finale belong to Chrome?** Every pixel is authored from keystroke to proof — then the most emotional step (the document leaving the shop) is a foreign print dialog and a toast that dies under it. What would a designed pre-flight moment look like?
2. **If the source of truth is text, why 32 plates?** Would melting half the toolbar down — keeping structure, folding inline styling behind one press — make the workshop calmer without costing Jordan anything the empty state doesn't teach?
3. **The workshop wears Garamond and brass; its documents default to "Modern — clean sans."** Deliberate separation (the pressman's apron never touches the page), or the product hiding its taste exactly where students most need a strong default?
